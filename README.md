# Flagkit

Flagkit is a production-grade feature flag management platform built to demonstrate scalable backend engineering concepts and real-world feature flag infrastructure.

### Key Features

- Boolean and multivariate feature flags
- Attribute-based user targeting
- Percentage-based gradual rollouts
- A/B experimentation and deterministic variant assignment
- Environment-based flag management
- Centralized feature flag evaluation
- Scalable and efficient flag evaluation architecture
